# UI 리디자인 설계

## 목표

현재 "AI가 만든 것 같은" UI를 걷어내고, 캘린더 중심 + 추천 톤의 캐주얼한 앱으로 전면 개편한다. 모바일 퍼스트.

## 디자인 원칙

1. **컨테이너 최소화** — 카드/배경색/서피스 대신 타이포와 구분선으로 계층 표현
2. **장식 제거** — rounded-xl, backdrop-blur, gradient, shadow-lg 사용 안 함
3. **요소 줄이기** — 뱃지/pill/태그 남용 금지. 정보 밀도보다 가독성
4. **일관된 스페이싱** — 버튼 패딩, 여백이 균일하게
5. **Tossface 이모지** 유지

## 컬러

```
--bg: #fff (라이트) / #0f0f0f (다크)
--fg: #000 / #e5e5e0
--g3: #444 / #ccc
--g5: #999 / #777
--g7: #ddd / #333
--g9: #f5f5f5 / #111
--point: #e8390e / #ff6633
```

오렌지 액센트는 추천 텍스트 강조에만 한정 사용. 음식 타입별 컬러 시스템(기존 FOOD_COLORS) 폐지 — 이모지가 구분 역할을 대신함.

## 타이포

- **본문 폰트**: Wanted Sans (기존 Pretendard Variable 대체). 기기 간 일관성 확보 목적. woff2 셀프호스팅.
- 추천 타이틀: 18px / 800 / letter-spacing -0.03em
- 본문: 15px / 700
- 서브: 12-13px / color g5
- 시간: tabular-nums
- **이모지**: Tossface 유지

## 페이지 구조

### 1. 온보딩 (최초 1회)

3장 슬라이드, 스와이프 + 다음 버튼. 건너뛰기 없음.

- 슬라이드 1: "배고픈 카이스트인을 위한 공짜밥 알리미"
- 슬라이드 2: "캘린더로 한눈에, 놓치는 밥 없이"
- 슬라이드 3: "사전신청도 원클릭으로"

온보딩에서 프로필 수집하지 않음. 마지막 슬라이드 "시작하기" → 메인으로 이동.

### 2. 메인 화면 (/events)

구조 (위→아래):

```
[헤더: 🍚 쌀먹  ──────  프로필 · + 제보]
[추천 블록]
[구분선]
[월간 캘린더]
[날짜별 행사 리스트]
```

#### 헤더
- 로고 (🍚 쌀먹, 16px 900) + 우측에 텍스트 링크 ("프로필", "+ 제보")
- border 없음, 심플한 flex 배치
- sticky 하되 backdrop-blur 사용 안 함 — 불투명 배경

#### 추천 블록
상황에 따라 문구가 바뀜:

| 상황 | 문구 예시 |
|------|----------|
| 오늘 행사 있음 | "오늘 점심, **쉐이크쉑** 어때요?" |
| 오늘 없고 내일 있음 | "내일 점심, **서브웨이** 어때요?" |
| 이번 주 내 없음 | "아 쌀먹 좀 하자..." |

추천 아래에 해당 행사 리스트: 이모지 + 음식명(주) + 행사명·장소(부) + 시간

#### 캘린더
- 월간 그리드, 행사 있는 날에 dot (여러 개면 bar)
- 오늘 날짜는 point 색
- 날짜 탭 → **바텀시트**로 해당 날짜의 행사 목록 표시
- 월 이동 화살표

#### 행사 리스트
- 날짜 구분자 ("내일 9/4 목", "9/6 토")
- 각 행사: 시간 | 이모지 | 음식명 + 행사명·장소 | (신청 플래그)
- border-top 1px으로 구분, 카드 없음

### 3. 행사 상세 (/events/[id])

- 헤더: ← 뒤로 + "행사 상세"
- 음식 정보가 타이틀보다 위에 (이모지 + 음식명)
- 행사명, 시간, 장소, 대상
- 설명 (있으면)
- 참석 섹션 (나도 갈래요)
- 액션 버튼: 자동신청 / 캘린더 추가 / .ics

### 4. 프로필 수집 (토스식, 모달/전체화면)

자동신청 또는 "나도 갈래요" 탭 시, 프로필 미설정이면 트리거.

한 필드씩 순차 입력:
1. "이름이 어떻게 되세요?" → 텍스트 입력
2. "학번을 알려주세요" → 숫자 입력
3. "어느 학과 소속이세요?" → 칩 선택
4. "이메일 주소를 입력해주세요" → 이메일 입력

- 완료된 필드는 위에 쌓이며 애니메이션
- ← 뒤로 가면 이전 단계로 돌아가 수정 가능
- 완료 시 localStorage 저장 + 토스트 알림
- 이후 원래 액션(자동신청/참석표시) 자동 실행

### 5. 제보 (/submit)

- 헤더: ← + "쌀먹 제보"
- 기존 폼 유지하되 스타일만 변경 (border 없는 input, 구분선 기반)
- 음식 타입 선택: 칩 형태 유지하되 배경색 제거, border만

### 6. 피드 (/feed)

- 헤더: ← + "업데이트"
- 시간순 텍스트 리스트, 기존 구조 유지하되 스타일 통일

### 7. 바텀시트 (캘린더 날짜 탭)

- 오버레이 + 아래에서 올라오는 시트
- 선택한 날짜 + 해당 행사 목록
- 행사 탭 → 상세 페이지로 이동
- 시트 밖 탭 또는 아래로 스와이프 → 닫기
